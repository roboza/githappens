01 / WHAT HAPPENED?

Pick your disaster. We have a button for that.

$ git commit -m "quick fix" # on main

Move it, then undo the mess.

Create a branch right on that commit, then reset main back where it was. Changed your mind? Undo puts everything back, because the move was journaled before it ran.

02 / THE TOOLKIT

Everything you reach for at 5:58 on a Friday.

A graph you can read

Lanes, ref labels, search and filter, and Jump to HEAD. Virtualized, so very large repos still scroll.

Undo. Redo. Breathe.

Core actions are journaled before they run, so a bad reset, merge or checkout is one shortcut away from never having happened.

Conflicts, predicted

Local conflict prediction with git merge-tree warns you before you merge. When it does happen, there's a built-in 3-way merge tool.

Drag, drop, done

Drop a branch on another to merge, rebase, fast-forward or push. Cherry-pick, revert and reset from the graph.

Stage by the line

Stage, unstage or discard by file, hunk or line. A commit composer with amend and visible hook output.

Still a terminal person?

There's an integrated terminal, a command palette and rebindable shortcuts. Your muscle memory is safe here.

Also in the box: interactive rebase · file history & blame · in-app editor · stashes · submodules · worktrees · Git LFS · SSH agent · profiles & themes

03 / YOUR REPO, YOUR BUSINESS

No account wall. No cloud unless it's yours.

githappens is fully functional on its own and makes no cloud calls. Want team features? Run the cloud server yourself and point the app at it.

  • +End-to-end encrypted settings sync

  • +Teammate overlap warnings, before two people edit the same thing
  • +Sign in with GitHub, GitLab, Google or email links
